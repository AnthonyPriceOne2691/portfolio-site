# Spec: каркас витрины + Home (слайс 1 MVP)

## Problem

Репозиторий содержит контур и заглушку вместо сайта: `index.astro` печатает
список проектов без разметки. Витрины нет. Дизайн-документ v0.7 описывает её
целиком (§4.1–4.6, §7, §8.5), Phase 1 оценена в 3–7 дней и в один слайс не
влезает — только контент это 8 markdown-файлов.

Этот слайс делает витрину **проходимой**: рекрутёр открывает ссылку, видит hero,
три цифры и карточки, кликает в проект, переключает язык. Тексты кейса, видео и
About приходят следующими слайсами и не блокируют этот.

## Users / stakeholders

Рекрутёр или нанимающий менеджер, открывший ссылку из Telegram / LinkedIn / hh.
Путь на 60 секунд (§4.2 дизайна) — линза приёмки: превью ссылки → hero (5 с) →
три цифры (10 с) → карточка проекта (30 с) → контакт (60 с).

## In scope

- **Каркас представления:** `Base.astro` (head, meta/OG §8.5, hreflang-пары,
  JSON-LD `Person`), `Nav.astro` (sticky, без бургера на мобиле), `Footer.astro`,
  переключатель EN/RU, `404.astro`.
- **Токены и стиль** по §7.1.2: тёмная тема, ink `#0F1214`±, один акцент
  «gate green», display + body + mono, видимые focus-стейты,
  `prefers-reduced-motion`.
- **Home** по §4.2: hero (имя, роль, тезис §10.4, статус-строка, 2 CTA) +
  contract-gate (§7.1.1, один прогон анимации) + impact strip (3 цифры §10.6) +
  featured LinkBuilder + 3 карточки + How I work (§10.5) + Contact (§4.5).
- **Страницы проектов** в структурном объёме: `[slug].astro` по скелету §4.4 —
  breadcrumb, заголовок, статус, meta-строка, тело из markdown, секция
  `[✓] Under contract`, proof-ссылки, кольцо «Next project →». Слоты видео
  деградируют, когда медиа нет.
- **`/projects`** — авто-список из коллекции.
- **Контент:** 4 проекта × EN + RU, frontmatter по §8.2.1, тела — короткие
  (card copy §5.1–5.4). Полный текст кейса LinkBuilder — слайс 2.
- **RU — в этом же слайсе, не «потом».** Конституция допускает отставание только
  явной строкой в спеке; строки не будет. RU = перевод EN с адаптацией тона под
  hh (§7.3).

## Out of scope

- **Медиа:** тизеры, постеры, скриншоты, видео (Phase 0 дизайна не сделана —
  нечего встраивать). Шаблон обязан корректно рендериться без них.
- **Полный кейс LinkBuilder** (§5.1) и About (§10.3) — слайс 2.
- **CV в nav** — файлы лежат вне репозитория; публикация PDF требует решения
  человека (см. Open questions).
- **Деплой на Cloudflare Pages** и домен — слайс 3, нужен аккаунт владельца.
- Аналитика, light-тема, per-project OG, hover-тизеры — post-MVP по §7.1.3.

## Acceptance (observable)

- [ ] `npm run build` зелёный; в `dist/` есть `index.html`, `ru/index.html`,
      `projects/index.html` и 4 страницы проектов в обеих ветках.
- [ ] Каждая страница несёт `hreflang` en/ru + `x-default`, OG-теги и
      JSON-LD `Person`; title/description на языке страницы.
- [ ] Home и страница проекта открываются с клавиатуры: виден focus, работает
      skip-link, переключатель языка достижим табом.
- [ ] При `prefers-reduced-motion: reduce` contract-gate и count-up статичны.
- [ ] На ширине 360 px нет горизонтального скролла.
- [ ] `pre-commit run --all-files` зелёный при чистом env; гейты формы видят
      новые файлы (числа выросли против 4/2/1/3).
- [ ] CI зелёный, `merge_guard.sh` пропускает мерж.

## Non-functional

- Каркас страницы < 300 KB, LCP < 1.5 s (§7.1.3). Медиа в слайс не входят,
  поэтому бюджет проверяется на «голой» вёрстке — это его лучший момент.
- Контраст ≥ 4.5:1, включая акцент на тёмном фоне (§7.1.3).
- Гейты на коммите укладываются в бюджет §8.6.

## Решения по открытым вопросам (человек, 2026-08-07)

1. **Цифра тестов — `6,500+`**, как решил дизайн §14. Следствие названо, а не
   замолчано: CV и `PORTFOLIO_LINKBUILDER_CASE.md` держат `4,200+`, и пока они
   не обновлены, расхождение существует и нарушает принцип 5 конституции.
   Это **долг с исполнителем и сроком** (задача T13), а не «потом».
2. **«5 → 1» — смягчить формулировку.** Причина: §5.1 дизайна прямо отмечает,
   что в репозитории замена команды не зафиксирована; источник — CV. Говорим о
   свойстве системы, а не о сокращении людей. Предлагаемые тексты (утверждаются
   вместе со спекой):
   - hero: ~~«one operator replaced a team of five»~~ →
     **«Production SaaS built to run with a single operator»**;
   - impact strip, первая цифра: ~~«5 → 1 · outreach team replaced by one
     operator»~~ → **«1 operator · the whole outreach pipeline runs on one
     person plus the platform»**.
   Тезис остаётся сильным, но защищается кодом, а не воспоминанием.
3. **CV в nav — не в этом слайсе.** PDF не кладём в публичный репозиторий, пока
   вы сами не просмотрите оба файла на телефон, адрес и NDA-следы. Место под
   ссылку в nav резервируется, чтобы её добавление не перекраивало вёрстку.
4. **`@astrojs/sitemap` — берём** (routine, решение исполнителя): ручной sitemap
   на двух языковых ветках с hreflang — ровно тот код, который расходится с
   контентом молча. Объявляется строкой `new_dependency:` в STATUS на T7.
