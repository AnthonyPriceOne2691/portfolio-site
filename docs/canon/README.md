# Снимок канонов (вариант C, CQG §5 шаг 11)

Копия четырёх канонов и `stack_selftest.py` на момент развёртывания. Правится
**только** переносом из репозитория канонов — локальные правки здесь разъезжаются
с источником молча.

⚠ **Запускать самопроверку надо С ПУТЁМ, а не из корня репозитория:**

```bash
python3 docs/canon/stack_selftest.py docs/canon    # 68 блоков, 0 failures
```

Без аргумента скрипт ищет каноны от текущего каталога и в корне проекта даёт
`4 failures / 0 blocks` — это НЕ поломка снимка, а «смотрел не туда». В CI путь
передаётся аргументом (шаг «Canon payload selftest»), поэтому там верно; ложную
панику ловит только человек, запустивший из корня.

Каталог исключён из breaker'ов (Delivery §3.4), из ruff и из хука
`check-added-large-files`: это механика контура, а не поставка.
