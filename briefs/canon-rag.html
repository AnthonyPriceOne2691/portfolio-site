RAG over a rulebook

Cite the exact clause — or refuse

Offline question answering over four engineering rulebooks: every answer carries an exact (file, §) address — or says the question isn’t covered. A case study in evaluation discipline; corpus and answers in Russian.

  • 0 / 680answers without an address
  • 72%recall@20 on a clean holdout
  • 58predictions written before the runs
  • 0.666nDCG@10 against a 0.665 anchor

The problem

An answer is only as good as the clause behind it, and the clause must be checkable. Almost half of the § numbers exist in more than one document, so only a (file, §) pair is a valid citation. A small model given any context never refuses on its own, and questions written by the author overstated retrieval by 28 points.

What it does

  • Indexes addressed § sections twice — lexical and dense
  • Refuses before generation when a question barely overlaps the rules
  • Fuses both rankings; a local model answers in one line with an address
  • Measures itself on independent questions, logging every holdout look

Architecture

How it flows

  1. Sections keep their (file, §) address; small child chunks point back to the parent.
  2. A question meets the refusal gate first — too little overlap, and it stops there.
  3. Rankings are fused; a local model keeps up to five fragments and answers in one line.
  4. Offline, a validator sorts every answer: correct, wrong, refused, unaddressed or fabricated.

Worth knowing

  • A hand-written BM25 matched a published anchor.nDCG@10 0.666 against 0.665 on BEIR/SciFact, 300 queries — with the pass bar committed before the run.
  • The gate reveals the loss; it doesn’t cause it.Without it, 0 of 7 false refusals became useful answers, and 3 of 3 correct refusals became confident wrong ones.
  • Author-written questions flattered retrieval by 28 points.The first run on 394 independent questions switched the retriever from lexical to hybrid.

Decisions that shape it

Hybrid retrieval over pure lexical or pure vector

on 314 independent questions hybrid reached 76% recall@20 against 61% lexical and 71% dense; a pre-registered paired test on the clean holdout confirmed it — 72% against 57%, p = 0.0018.

fusion discards score magnitude, so refusal needs its own gate.

The § section as the unit, (file, §) as the key

almost half of the § numbers collide across documents. Parent-document retrieval keeps the address and lifted dense top-5 from 6% to 61%.

uneven sections, and special cases for chapters without text.

Citations by structure, not by prompt wording

with fragment headers 8 of 8 answers carried a file-qualified address; without them, 1 of 8 — whatever the prompt said.

a valid citation is not a correct one, so correctness is measured separately.

A lexical refusal gate, not the model’s judgment

with empty context the model refused 210 of 210; given any context, it refused 0 of 102.

the gate measures word overlap, so short real questions are refused more often.

A ledger of looks; predictions before runs

the first architecture choice was made with the holdout inside the denominator. A pre-registered rerun put the cost at about 4 points — and the ranking held.

slower loops, and negatives get published.

Calibrate the ruler on someone else’s benchmark

internal numbers can’t validate the instrument itself. BM25 matched the BEIR anchor within 0.001 — and the log calls the third decimal “partly luck”.

it validates only the lexical channel, in English.

Limits are stated above the strengths. The README opens with the honest table: exact (file, §) accuracy is 50% on an independent holdout — each number with its own configuration and population, so no headline figure can hide behind a friendlier one.

Where it transfers

Wherever an answer is only as good as the clause behind it: internal policies and HR handbooks, compliance and regulatory manuals, security standards, SOPs, support knowledge bases. What carries over is the architecture, not the model — index at clause level, make (document, clause) the citation key, enforce citations by structure and give refusal its own path — and the evaluation harness carries over unchanged, so a new corpus means re-measuring, not re-arguing.
