настоящего браузера, со зрением по скриншотам. Каждый вызов модели — на
ноутбуке.

- Факт с высокой уверенностью обязан совпасть цитатой с реальной страницей, иначе понижается
- Действия разведены по уровням автономности и обратимости: необратимое запрещено
