Цикл «наблюдай → планируй → действуй» поверх настоящего браузера, с локальным
зрением по скриншотам. Каждый вызов модели выполняется на ноутбуке.

- Факт с высокой уверенностью обязан совпасть цитатой с реальной страницей, иначе понижается
- Действия разведены по уровням автономности и обратимости: необратимое запрещено
- Anti-bot проходит человек в видимом браузере, а не спуфинг
