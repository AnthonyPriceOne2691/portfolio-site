Поиск по четырём сводам правил: вопрос → гибридный поиск → отборщик → локальная
модель → ответ с адресом либо отказ. Всё на ноутбуке, без облака.

- BM25, RRF-гибрид и parent-document retrieval написаны руками, зависимостей вне stdlib нет
- Прибор поверен на чужом полигоне: nDCG@10 **0.666** против якоря 0.665 (BEIR/SciFact, 300 вопросов)
- recall@20 — **76%** [71..80] на 314 независимых вопросах
- На 680 ответах: ни одного без адреса, выдуманных пар 0.3%

Пределы названы, а не спрятаны: точность точной пары «файл + раздел» — 50% на
независимом holdout, и это написано в README раньше, чем достоинства.
